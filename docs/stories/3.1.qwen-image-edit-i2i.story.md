## Story

**As** a servegate consumer integrating image editing into a portfolio app,
**I want** a new SDK `client.edit({ prompt, image, ... })` experience and a payload-shape-based i2i branch in the existing `/jobs` async contract,
**so that** I can request a Qwen-Image-Edit transformation with the same submit/poll flow as T2I, while preserving the existing T2I path and keeping inference self-hosted under Apache 2.0 licensed assets.

## Acceptance Criteria

1. **Payload-shape dispatch:** `serverless/handler.py` routes requests based on `input_image_b64`: present → Qwen i2i workflow; absent → existing FLUX.1-schnell T2I workflow unchanged.
2. **Async contract preserved:** `POST /jobs { prompt, input_image_b64, ... }` returns `202 + { job_id, status_url }`, and `GET /jobs/{id}` returns `200 + { output: { image_b64, metadata } }` when the i2i job completes.
3. **T2I regression zero:** `POST /jobs` without `input_image_b64` continues to use the existing T2I path with no behavior, schema, or response contract change. Existing T2I tests remain green.
4. **Qwen i2i workflow:** new handler branch builds a Qwen-Image-Edit ComfyUI workflow using the approved Apache 2.0 model artifacts plus Lightning 8-step LoRA, and post-processes generated output to preserve input dimensions.
5. **Input validation:** the i2i branch rejects exact 1:1 aspect ratio images, enforces a decoded image payload cap ≤ 8 MB, downsamples inputs larger than 1 MP to ≤ 1 MP while preserving aspect ratio, and accepts only `image/png`, `image/jpeg`, and `image/webp`.
6. **SDK additive surface:** `sdk/src/client.ts` adds `edit(input: EditInput): Promise<GenerateOutput>` with `image: Buffer | Uint8Array | Blob | string`, binary/base64 normalization, schema validation, and reuse of the existing submit/poll logic. `generate()` remains unchanged.
7. **Documentation and compliance:** add API reference, SDK README EN+pt-BR, TERMS/PRIVACY EN+pt-BR updates, and dev onboarding guidance for i2i. All public docs must pass Story 2.8 sanitization checks.
8. **Provenance documented:** network volume NOTICE or equivalent artifact documentation must record the Apache 2.0 license chain for Qwen artifacts and Lightning LoRA.

## Out of scope

- High-resolution tiling beyond 1 MP inputs.
- ControlNet or advanced structural overlay support.
- Multi-image reference composition.
- Hosted-API fallback tiers.
- Webhook callback contract changes.
